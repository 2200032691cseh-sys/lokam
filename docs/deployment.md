# Deployment strategy

Proposal for development and private beta. Official plan documents reviewed November 24, 2026. Recheck at enrollment and before release. No accounts were provisioned.

| Candidate | Current documentation and impact |
|---|---|
| Render free app | Sleeps at 15 minutes idle; documentation estimates about one minute to wake. 750 workspace hours/month, ephemeral filesystem and no free dedicated worker assumption. Cold-start p75 is a launch risk. [Render free](https://render.com/docs/free) |
| Neon Free | 100 CU-hours, 1 GB storage and 5 GB public transfer per project monthly where applicable. Compute sleeps after 5 minutes; 6-hour instant restore history. Quota exhaustion can suspend access. Docs list pg_trgm and vector; verify both with target credentials. [Plans](https://neon.com/docs/introduction/plans) · [Extensions](https://neon.com/docs/extensions/pg-extensions) |
| Cloudflare R2 Standard | 10 GB-month, 1M Class A, 10M Class B monthly, free internet egress. Billing enrollment and overage exposure must be confirmed in the account. Use private buckets and request quotas. [Pricing](https://developers.cloudflare.com/r2/pricing/) · [Enrollment](https://developers.cloudflare.com/r2/get-started/) |
| Cloudflare DNS/CDN | Optional for owned domain; use provider HTTPS hostname in development. Cache versioned static assets only until publication/withdrawal semantics are reviewed. Domain purchase and ownership are open. [DNS](https://developers.cloudflare.com/dns/) |
| Resend | Free 3,000/month and 100/day listed. Production sending requires verified DNS domain. Sender availability, account eligibility and delivery are unverified. Start locally with console email. [Pricing](https://resend.com/pricing) · [Verified domains](https://resend.com/docs/dashboard/domains/introduction) |
| GitHub Actions | Standard public runners free, private quotas plan-dependent. Scheduled runs can be delayed; public schedules can disable after inactivity. Use CI and best-effort maintenance only. Verify account minutes and payment thresholds. [Billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions) · [Scheduling](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows#schedule) |
| Sentry | Free Developer option exists. Verify effective account allowances, commercial terms, processing region and retention; use sanitized structured local logs if unavailable. Disable body, session replay and personal data collection. [Pricing](https://sentry.io/pricing/) |

Develop on native Windows with uv, PostgreSQL and local filesystem media. Use Linux WSGI production build with locked dependencies and collected static assets. Start with buildpacks if sufficient; Docker requires a demonstrated packaging benefit. Configure environment variables for DB TLS, pool limits, hosts, provider keys, sender and storage. Run expand-only migrations with dedicated credentials before routing traffic. Run deploy checks and smoke tests. Revert to the prior image only with compatible schema. Use direct DB connections for migrations and backups; exercise portable pg_dump and S3-compatible migration.

Use a bounded command via monitored local scheduling for beta or a hosting-supported runner where verified. Recovery email requires measured delivery and must outlive crashes; a delayed schedule alone is insufficient. No scheduler or worker SLA has been verified. Public release depends on meeting recovery, accessibility, latency, email, backup, legal and quota gates. If the free tier fails, keep the beta bounded and choose an approved paid or otherwise verified host for launch.
