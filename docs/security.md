# Security model

Trust boundaries are browser, app, database/object storage, worker, provider and optional inference. Use Django CSRF and escaped templates, parameterized ORM, POST mutations, scoped lookups and validated forms. Enforce HTTPS/HSTS, Secure and HttpOnly cookies, appropriate SameSite, host/proxy validation, CSP, nosniff and Referrer-Policy. Rotate sessions on login and invalidate on recovery/deletion. Use Argon2id with measured costs, bounded shared account/network throttling, generic auth responses and expiring one-use email credentials. Require recent reauthentication for deletion and exports, administrator MFA, least-privilege credentials and audited actions.

Provider clients use explicit hosts and endpoints, bounded time and bytes, restricted redirects and public-address validation through connection time. Ignore user-supplied arbitrary image fetch targets. Quarantine uploads, inspect signatures, cap bytes/pixels/frames, re-encode with Pillow and strip EXIF/GPS. Reject active formats. Treat import content as data, cap nesting/archive expansion and neutralize spreadsheet-formula cells in CSV exports. Redact provider credentials, tokens, private content and email addresses from logs. Review dependency vulnerabilities and exercise cross-user authorization across every indirect surface.
