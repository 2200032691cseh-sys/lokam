# Recommendation engine

Use explicit favourites, saves, ratings, selected topics, tags, creators, locations, cultures, languages, characters and feedback. Favourites outweigh tentative saves. Normalize total evidence per item to avoid overweighting densely tagged works. Cold start offers curated topics, optional selection and direct search. Keep activity telemetry outside preference scoring.

Generate bounded pools from verified graph paths (two hops initially), metadata overlap, shared creators/entities, provider suggestions, semantic similarity and controlled exploration. Cap fan-out and use permitted predicates. Keep verified facts, provider suggestions, computed similarity and personal connections distinct. Use an initial normalized blend of preference .30, factual .25, metadata/entity .20, semantic .10, provider .05 and novelty .10. Renormalize for methods globally unavailable in the run. Dismissal excludes, negative theme feedback lowers bounded score. Apply stable tie-breaks, creator/domain caps, deduplication and an exploratory slot. Use a separate rediscovery group for saved items.

Authorize before candidate selection and again before reading evidence. Explain via the strongest eligible reason, with verified predicates for facts and qualified language for similarity. Reset clears selections, feedback and snapshots, with a choice to start fresh or rebuild from current saves. Group Discover by domain, subject, history, culture, geography and exploratory themes with finite pages and filters.

Compare multilingual-e5-small on CPU against graph/lexical baseline. Precompute canonical embeddings once per model/content version outside requests; use exact pgvector first and ANN only after measurement. Never embed private notes. Measure precision, cross-domain recall, diversity, coverage, attribution correctness, RAM and latency with English/Telugu, sparse, ambiguous, conflicting, missing data and outage fixtures. Require zero leaked evidence and zero falsely factual explanations. Keep collaborative filtering out of the initial architecture.
